# scnr2_viz

`scnr2_viz` supports analysis of scanners generated by the [sncr2](https://github.com/jsinger67/scnr2)
crate. It generates Graphviz visualizations for `scanner!` mode DFAs from Rust source files.

It parses a Rust file containing one or more `scanner!` macro invocations, builds scanner modes/DFAs
via `scnr2_generate`, and writes visualization artifacts.

## Features

- Generates Graphviz DOT output for scanner modes and DFA states
- Labels DFA transitions with disjunct character class IDs
- Exports disjunct character class definitions to a separate JSON file
- Uses token names from inline `token ... => <id>; // "<Name>"` comments for accept labels and mode
transition labels
- Optional direct SVG generation via Graphviz `dot`

## Usage

```powershell
cargo run -- -i .\input.txt -o output.dot
```

With SVG output:

```powershell
cargo run -- -i .\input.txt -o output.dot --svg-output .\output.svg
```

## CLI Options

- `-i, --input <PATH>`: Rust file containing at least one `scanner!` macro invocation
- `-o, --output <PATH>`: Path to generated `.dot` file
- `--macro-index <N>`: Zero-based index when multiple `scanner!` invocations exist (default: `0`)
- `--svg-output <PATH>`: Optional SVG output path (requires Graphviz `dot` in `PATH`)

## Generated Files

Given `-o output.dot`:

- `output.dot`: Graphviz DOT graph
- `output.classes.json`: Disjunct character class definitions (`scnr2_disjunct_character_classes_v1`)
- `output.svg` (optional): SVG rendered by Graphviz when `--svg-output` is provided
